01 / The question

How do you make model training and prediction repeatable and usable outside the environment where you first built them?

This project explores whether customer information can help predict interest in vehicle insurance. I connected separate components for ingestion, validation, transformation, model training, evaluation, and serving. I then explored packaging the service with Docker and connecting GitHub Actions with AWS S3, ECR and EC2.

02 / What the evidence showed

What was difficult—and what I learned.

A pipeline that runs is not automatically a reliable model. The original reported performance values need leakage-free reevaluation, so I have removed them rather than present unsupported precision. The work still taught me how application code, datasets, artifacts, CI/CD and cloud infrastructure depend on one another.
